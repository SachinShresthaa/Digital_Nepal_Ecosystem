# Contributing to Digital Nepal Ecosystem

Thank you for contributing to Digital Nepal Ecosystem! This document describes how to help the project and what standards contributors should follow.

## How to contribute

1. Fork the repository and create a feature branch from `develop`.
2. Keep your branch up to date by pulling `develop` regularly.
3. Work on one issue or feature at a time.
4. Open a pull request against `develop`.

## Pull request expectations

- Use clear, descriptive PR titles.
- Reference the related issue number when available.
- Provide a short summary of what changed and why.
- Include the testing steps you followed.
- Ensure the branch is up to date before merging.

## Coding and commit guidelines

- Write clean, readable code.
- Keep changes small and focused.
- Use consistent formatting and naming.
- Run any available tests before submitting.
- Use present-tense commit messages, for example:
  - `Add login flow`
  - `Fix bug in dashboard query`

## Collaboration rules

- Do not force-push to shared branches.
- Do not delete or overwrite `develop` or `main` directly.
- Create PRs for any non-trivial change.

## Communication

- Add a comment to the issue when your work is ready for review.
- Respond to review feedback and update the PR accordingly.
